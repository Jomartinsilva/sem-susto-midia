# Sem Susto — mídia pública

Repositório público que guarda só as imagens dos posts do canal **Sem Susto Viagens** (afiliados de turismo), em JPEG, usadas como `image_url` ao publicar pela Graph API da Meta (Instagram e Facebook).

A Meta busca a imagem direto do seu servidor, sem autenticação — por isso este repositório precisa ser público. Nenhum código, decisão interna ou documento do projeto fica aqui: isso continua no repositório privado `sem-susto`.

Estrutura: uma pasta por post, com o mesmo nome usado em `posts/` no repositório privado (ex.: `002-nome-do-post/slide-1.jpg`).
